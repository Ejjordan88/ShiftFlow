# ShiftFlow

A lightweight SwiftUI shift-management app designed to explore how software can improve everyday operational workflows.

## About the Project

ShiftFlow is a learning project inspired by my 15+ years working in hospitality and operations leadership.

The goal is to take workflows I understand from the real world and use them to develop practical software engineering skills.

Rather than building tutorial projects without context, I'm using familiar operational problems to learn how data, application state, user interfaces, and business logic work together.

## Current Features

- View shift tasks
- Mark tasks complete or incomplete
- Automatically track completed tasks
- Display real-time shift progress
- Dynamically update the interface as task state changes
